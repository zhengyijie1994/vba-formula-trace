# VBA 公式追踪与跳转工具集（自用宏.xlam）

一个面向 Excel / WPS 的 **VBA 加载项**（`.xlam`），核心功能是**公式错误追踪与根因定位**，并集成 **DeepSeek AI** 做智能分析，同时附带一批日常表格处理宏。

仓库内既提供**打包好的成品加载项**（`自用宏.xlam`，下载即用），也保留全部 **VBA 源码模块**（`.bas` / `.frm` / `.cls`）供二次开发。

## 📥 快速开始（成品加载项）

1. 下载 `自用宏.xlam`
2. 安装加载项：
   - **Excel**：`文件 → 选项 → 加载项 → 管理「Excel 加载项」→ 转到 → 浏览`，选中 `自用宏.xlam` 并勾选启用
   - **WPS**：`开发工具 → 加载项` 管理（或"设置 → 加载项"），添加该文件
3. 重启 Excel/WPS，按功能区/命令调用各功能
4. 首次使用 DeepSeek 功能前，打开 `frmDeepSeekSettings` 设置窗体填入 API Key（见「密钥安全」）

> ⚠️ 更新版本时：先把旧版从加载项管理里**取消勾选**，再导入新文件，避免同名冲突。
> 若在 WPS 里换了新文件却仍是旧功能，请**托盘退出 WPS 重开**（WPS 不会热重载 xlam）。

## ✨ 核心功能

### 🔍 公式追踪（`公式跳转1.bas`）

选中一个出错公式单元格，即可：

- **逐层下钻追踪** — 自动解析公式里的所有单元格引用（`A1`、`$A$1:$B$10`、整列/整行引用），逐个跳到上游单元格排查
- **结构化引用解析** — 支持 `表1[产品]`、`表1[@列名]`、`表1[[#数据],[列名]]` 等 Excel 表格引用
- **错误优先定位** — 自动识别引用范围内的错误值、0 值/空白、文本值，优先推送最可疑的上游引用
- **候选导航** — 快捷键循环浏览所有引用候选（N 确定 / D 深入 / B 返回 / A 切换模式 / R 根因 / Q 退出）
- **自动根因建议** — 给出"路径 → 根因候选 → 判断"的完整诊断结论
- **AI 深度分析** — 一键把公式、引用和值证据打包发给 DeepSeek，得到具体出错子表达式的分析

### 🔁 谁引用了我（`WhoRefsMe.bas`）

**下游依赖追踪**——反向查看"当前单元格被哪些公式引用"：

- **无需公式也能用** — 选中任意单元格（包括常量、无公式单元格），即可查看它被谁引用
- **分类展示** — 精确引用（`=B4/P8`）→ 小区域聚合（`SUM(A16:R16)`）→ 大区域查询（`V:V` 整列），自动排序
- **秒级响应** — 基于 Excel 原生 `Range.Dependents`，即使整列被上千公式引用也只收集前 300 条，不卡死
- **快速导航** — 「上一个/下一个」切换引用者并跳转，面板高亮当前公式中的目标地址
- **返回单元格** — 一键跳回起点

### 📊 值透视 / 找根因 / AI 分析（大范围优化）

对**大范围引用**（如 `明细!E2:E64953` 六万行）做了提速处理：

- **数组批量统计** — 一次读入 `Value2`/`Formula` 到内存数组，一遍分类（错误/空白/文本/0值/公式格），替代多次 `SpecialCells` 逐格扫描
- **真实数据喂给 AI** — 提供范围统计 + 首个异常单元格地址 + 真实样本，不是空标签
- **手动计算保护** — 打开面板期间临时切换手动计算，避免读取值触发 FILTER/UNIQUE 等慢公式重算导致卡死
- **采样去重** — 采样值全局去重，同值只报一次并标注"前 10 格相同"，不同值最多给 4 个去重示例
- 实测：六万行引用的值透视从"卡死几分钟"降到 **百毫秒级**

### 🤖 AI 对话（`AIWorksheetAgent.bas` + `DeepSeekAI.bas`）

- 与 AI 协作操作表格：检查公式、读取数据、写值、公式、格式、筛选排序
- 所有修改**先预览、确认后才执行**，内置撤销栈，默认弹窗确认
- DeepSeek 对话窗口（`frmDeepSeekChat`），支持流式对话与 Token 用量统计
- **分析对象固定**：打开面板时锁定当前选中单元格，面板打开期间鼠标点到哪都不换分析对象；要换就关掉重开

### ✍️ AI 写公式（`AI写公式.bas`）

专用窗体，输入中文需求 → AI 生成公式 → 写入单元格 → **回读验证 → 自动修正**：

- 参数调优：公式长度上限 4000、每区域读格数上限 120
- 表头理解：自动定位目标表表头并注入（含表头字典，AI 第一轮不再把"产量"猜成"电量"）
- 接入 AI 对话的 **23 个只读工具**（`list_sheets` / `get_sheet_structure` / `read_range` / `inspect_table_profile` / `inspect_workbook_overview` / `inspect_formulas` / `find_cells` / `evaluate_formula` / `find_error_cells` 等）
- 空正文保护：`max_tokens` 被思考吃光导致"返回成功但内容为空"时，自动关闭思考重试一次
- 复核轮容错：`final` 键冒号后带空格/前面带推理也能正确判定

## 🔐 密钥安全

- **代码中不包含任何明文 API Key**
- API Key 通过 Windows DPAPI（`CryptProtectData`）加密后存入注册表（`GetSetting`），仅本机当前用户可解密
- V10.1.16 起为**原生 `CryptUnprotectData` 解密**，不再依赖拉起 powershell 子进程（旧方式被杀软拦截/超时会静默返回空，导致"密钥看着全丢了"）
- 换 xlam 不会丢密钥；仓库可放心公开分享
