# VBA 公式追踪与跳转工具集

一个面向 Excel / WPS 的 VBA 工具集合，核心功能是**公式错误追踪与根因定位**，并集成 **DeepSeek AI** 做智能分析。同时附带一批日常表格处理宏。

## ✨ 核心功能

### 🔍 公式追踪（`公式跳转1.bas`）

选中一个出错公式单元格，即可：

- **逐层下钻追踪** — 自动解析公式里的所有单元格引用（`A1`、`$A$1:$B$10`、整列/整行引用），逐个跳到上游单元格排查
- **结构化引用解析** — 支持 `表1[产品]`、`表1[@列名]`、`表1[[#数据],[列名]]` 等 Excel 表格引用
- **错误优先定位** — 自动识别引用范围内的错误值、0 值/空白、文本值，优先推送最可疑的上游引用
- **候选导航** — 快捷键循环浏览所有引用候选（N 确定 / D 深入 / B 返回 / A 切换模式 / R 根因 / Q 退出）
- **自动根因建议** — 给出"路径 → 根因候选 → 判断"的完整诊断结论
- **AI 深度分析** — 一键把公式、引用和值证据打包发给 DeepSeek，得到具体出错子表达式的分析

### 🔁 谁引用了我（`WhoRefsMe.bas`）

**下游依赖追踪**——反向查看"当前单元格被哪些公式引用"：

- **无需公式也能用** — 选中任意单元格（包括常量、无公式单元格），即可查看它被谁引用
- **分类展示** — 精确引用（`=B4/P8`）→ 小区域聚合（`SUM(A16:R16)`）→ 大区域查询（`V:V` 整列），自动排序
- **秒级响应** — 基于 Excel 原生 `Range.Dependents`，即使整列被上千公式引用也只收集前 300 条，不卡死
- **快速导航** — 「上一个/下一个」切换引用者并跳转，面板高亮当前公式中的目标地址（P9 / A16:R16 整段）
- **返回单元格** — 一键跳回起点

### 📊 值透视 / 找根因 / AI 分析（大范围优化）

对**大范围引用**（如 `明细!E2:E64953` 六万行）做了提速处理：

- **数组批量统计** — 一次读入 `Value2`/`Formula` 到内存数组，一遍分类（错误/空白/文本/0值/公式格），替代 5 次 `SpecialCells` 逐格扫描
- **真实数据喂给 AI** — 提供范围统计 + 首个异常单元格地址 + 真实样本，不是空标签
- **手动计算保护** — 打开面板期间临时切换手动计算，避免读取值触发 FILTER/UNIQUE 等慢公式重算导致卡死
- 实测：六万行引用的值透视从"卡死几分钟"降到 **百毫秒级**

### 🤖 AI 表格助手（`AIWorksheetAgent.bas` + `DeepSeekAI.bas`）

- 与 AI 协作操作表格：检查公式、读取数据、写值、公式、格式、筛选排序
- 所有修改**先预览、确认后才执行**，内置撤销栈
- DeepSeek 对话窗口（`frmDeepSeekChat`），支持流式对话与 Token 用量统计

### 🔐 密钥安全

- **代码中不包含任何明文 API Key**
- API Key 通过 Windows DPAPI（`CryptProtectData`）加密后存入注册表（`GetSetting`），仅本机当前用户可解密
- 仓库可放心公开分享

## 🚀 快速开始

1. **导入模块**：打开 Excel/WPS → `Alt+F11` → 菜单 `文件` → `导入文件`，选择 `.bas` / `.frm` / `.cls` 文件导入
2. **设置 API Key**（可选）：运行 `frmDeepSeekSettings`，填入 DeepSeek API Key（本地加密保存，不会上传）
3. **使用公式追踪**：
   - 选中一个返回错误的公式单元格
   - 运行 `TraceFormulaError`（可绑定快捷键）
   - 按提示使用 N / D / B / A / R / Q 浏览候选引用，定位根因
4. **使用谁引用了我**：
   - 选中任意单元格（有无公式均可）
   - 在公式追踪面板点「谁引用了我」
   - 用「上一个/下一个」切换引用者并跳转
